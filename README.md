# 👑 EMPIRE-OS

## ⚙ Installation

```bash
git clone https://github.com/yourusername/EMPIRE-OS.git

cd EMPIRE-OS

pip install -r requirements.txt

streamlit run app.py
```

---

## 🔑 Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=YOUR_GROQ_API_KEY
```

Optional:

```env
APP_ACCESS_PASSWORD=YOUR_ACCESS_PASSWORD
```
